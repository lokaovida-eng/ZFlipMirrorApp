**ZFlip Cover Mirror** is a single-purpose, high-performance Android utility that enables 1-tap real-time screen mirroring from the main inner display onto the outer cover display (Flex Window) of **Samsung Galaxy Z Flip 5, Z Flip 6, and Z Flip 7** smartphones.

## ✨ Key Features

- 🖥️ **1-Tap Mirroring**: Single toggle button to start or stop mirroring the main display to the outer cover screen.
- ⚡ **Zero-Latency Display Manager**: Uses Android Presentation & DisplayManager APIs for instant cover screen output.
- 🔋 **Battery-Optimized Foreground Service**: Low-overhead background service to maintain mirroring without phone sleep issues.
- 📳 **Haptic Feedback**: Tactile vibration when toggling mirroring mode.
